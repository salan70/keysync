# Web UI の使い方

リポジトリで `just ui` を実行し、Chrome で <http://127.0.0.1:5178/> を開きます。\
終了するときは、ターミナルで Ctrl+C を押します。\
押せないボタンは、横に理由が表示されます。

## キーを割り当てる

1. ヘッダーで `Cornix LP`、`Mac ANSI`、`Mac JIS` のいずれかを選びます。
2. 盤面のキーを選びます。
3. 盤面の下の picker から keycode を選びます。\
   選んだ時点で保存されます。

- tap と hold を分けるときは、編集パネルの `picker の適用先` で `Tap` か `Hold` を選びます。
- picker に無い keycode は、編集パネルの `raw keycode・表示名` で入力します。
- layer は盤面の上の `L0` `L1` … で切り替えます。

Mac では、割り当ての無いキーは layer 0 で入力をそのまま通し、layer 1 以上で何も出しません。\
Mac の設定ファイルが無いときは、盤面に出る `mac-keyboard.<layout>.yaml を作成` で作ります。

全体マップ、Tap Dance と Combo、検証、VIL の読み書きは、左端の入口から開きます。

## Cornix LP へ反映する

1. 左端の `実機` で `接続（機器を選ぶ）` を押し、Cornix LP を選びます。
2. `実機から読み込む` を押します。\
   接続しただけでは差分が出ません。
3. `実機へ Apply…` を押し、差分を確かめて書き込みます。
4. 書き込みが終わるまで接続を外さずに待ちます。

警告が出たら、内容を確かめた項目だけ承認します。\
途中で止まったときは、接続し直して手順 2 からやり直します。

workspace に `keymap.yaml` が無いときは、`実機 read で workspace を作成` で実機の設定から作れます。

## Mac へ反映する

1. ヘッダーでこの Mac の配列（`Mac ANSI` か `Mac JIS`）を選びます。
2. 画面下部の `kanata へ適用…` を押し、差分を確かめて `適用` を押します。

## 元に戻す

- **Cornix LP**: `実機` の `backup から復元` で直前の状態を画面へ読み戻し、通常どおり反映します。
- **Mac**: [CLI の戻し方](./cli.md#戻し方) を参照します。
