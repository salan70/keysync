# Mac の layer 1 以上で割り当ての無いキーを割り当てなしにする

## 依頼

layer 1 以上で設定していないキーを割り当てなしにしたい。
「layer 0 へ落とさず、何も出さない」の意味だと利用者に確かめた。

## 対応

判断は ADR 0050。
`generateKanataConfig` の layer 1 以上の末尾を `___ _` から `___ XX` へ替えた。
落下を前提にしていた 2 つの省略をやめた。
layer 0 と同値のキーも書き、`KC_TRNS` は layer 1 以上で `_` と書く。

UI は layer 1 以上の割り当ての無いキーを「割り当てなし」と `—` で出す。
Tap の初期値に素通しのキーを使うのは layer 0 だけにした。
layer 1 以上で Hold を外して物理キーと同じ keycode に戻っても、割り当てを消さずに keycode を書く。

## 確認

`kanata --check` を含む生成器のテストが通る。
実機への適用はしていない。
次の適用から、layer 1 以上の未設定キーは何も出さなくなる。
